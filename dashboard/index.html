Implied value is this board's own claim: a size curve fitted to the launches that already trade, a category offset, then momentum × track record × breadth — with a band around it read from the blind tests at the row's own size (the small line under each value). The plan net is the row's farm plan netted at its own band's low end; the verdict is FARM, THIN or SKIP. Click a row for the full workings, the traded launches nearest its size, the netting and the plan. “Records no token” is DefiLlama's record as of the snapshot date, not proof a token does not exist.

How the radar values a launch

Already trading — the calibration set

These protocols' tokens already trade, so the radar never ranks them: it shows the market's own value for each. They are the calibration set — the size curve and the category offsets are fitted to them, and the blind test is run against them.
